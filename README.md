# pikaos_chn_optimize

PikaOS 4 (COSMIC) 系统优化与中文环境配置参考。

使用 Agent（如 Claude Code、opencode）打开本项目，读取此 README 后即可按指引执行优化。

## 文件说明

- **`AI_INSTRUCTIONS.md`** — AI（opencode 等）操作指令，定义了执行优化的完整流程
- **`PikaOS系统优化及中文环境设置.md`** — 系统优化详细方案：内存/服务/输入法/NVIDIA/终端/字体/Shell
- **`软件安装推荐.md`** — 常用软件（微信、WPS、百度网盘、网易云音乐、VS Code 等）安装指南
- **`github.sh`** — GitHub SSH 一键配置脚本，用户手动执行（`bash github.sh`）。自动生成密钥、复制公钥到剪贴板、打开 GitHub 设置页、验证连接。AI 不处理此脚本。
